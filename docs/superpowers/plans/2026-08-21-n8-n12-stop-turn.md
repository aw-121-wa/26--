# N8→N12 STOPTURN 转前距离修复实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 仅将 N8→N12 STOPTURN 检测后的转向前距离从默认 18cm 调整为 15cm，并同步实际 215cm 段长例外。

**Architecture:** 保留 `cross_stop_turn()` 的普通 STOPTURN 默认路径和原有转向流程，在 `drive_cm` 初始化后增加一个精确的 N8→N12 条件覆盖。到达检测只修正该路线的强制到达排除条件，不触碰其他路线。

**Tech Stack:** STM32 C firmware, CMake, Python `unittest` contract tests.

## Global Constraints

- 只修改 `App/map/map.c` 中的 N8→N12 局部距离和强制到达例外。
- 不修改全局 STOPTURN 默认 18cm。
- 不修改 N8→N12 的 215cm、SPEED5、MUL2MUL、STOPTURN、140°角度和其他控制逻辑。
- 不修改 Fork Guard、P3→N3 25cm+8cm、N13→N18 25cm、PID、循迹、平台、语音、门和终点逻辑。
